Driver Earnings Tracker - iPhone PWA prototype

This is a working browser-based prototype for the approved app concept.
Data is stored locally in the browser on the device.

To use on iPhone:
1. Put these files on a web host that serves HTTPS.
2. Open the site's index.html URL in Safari.
3. Tap Share -> Add to Home Screen.
4. Launch "Driver Earnings" from the Home Screen.

This prototype includes:
- Individual trips: date/time, distance, price, ERP, waiting, cancellation
- Fuel refills: separate date, litres, price/litre, discount %, final paid
- CashCard top-ups: separate date and amount
- Dashboard and period reports
- Local storage
